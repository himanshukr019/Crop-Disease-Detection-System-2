# 🌿 CropScan AI — Crop Disease Detection System

A production-grade web application that uses a **MobileNetV2 CNN** to detect
plant diseases from leaf images, complete with a dark botanical UI and rich
confidence visualisation.

---

crop_disease_detector/
├── app.py                  # Flask backend (routes, file handling)

## ⚙️ Setup (Step-by-Step for Beginners)

### 1. Prerequisites
- Python 3.9, 3.10, or 3.11 (3.12 is not yet fully supported by TensorFlow)
- pip (comes with Python)
- ~3 GB disk space (for TensorFlow + synthetic images)

Check your Python version:
```bash
python --version
# or
python3 --version
```

---

### 2. Create a Virtual Environment (Recommended)
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

---

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

> 💡 If you don't have a GPU, TensorFlow will still work on CPU.
> Training will be slower (~10–20 min) but will complete fine.

---

### 4. Generate the Dataset
```bash
python generate_dataset.py
```

This creates **500 synthetic leaf images** (5 classes × 80 train + 20 test)
inside `dataset/`. Each image is a procedurally drawn leaf with class-specific
disease markings.

> ✅ You can **skip this step** if you have a real plant disease dataset
> (e.g., PlantVillage). Just place your images in `dataset/train/<ClassName>/`
> and `dataset/test/<ClassName>/`.

---

### 5. Train the Model
```bash
python train.py
```

What happens:
- Phase 1 (~10 epochs): trains only the new classifier head
- Phase 2 (~15 epochs): fine-tunes the upper MobileNetV2 layers
- Best weights are saved automatically via `ModelCheckpoint`
- Output: `model/crop_disease_model.h5` + `model/class_names.json`

Expected final test accuracy: **~90–98%** on synthetic data.

---

### 6. Run the Web Application
```bash
python app.py
```

Open your browser at: **http://localhost:5000**

## 🚀 Using the App

1. **Upload** a leaf image by clicking "Browse Files" or drag-and-drop
2. See the **live preview** with file metadata
3. Click **"Analyse Leaf"** (or press `Enter`)
4. Watch the animated loading sequence
5. View the **result card** with:
   - Disease name + emoji
   - Animated confidence ring
   - Severity badge
   - Treatment recommendation
   - Per-class probability bars
6. Use **"Copy Report"** to copy a text summary to clipboard
7. Click **"Scan Another Leaf"** to start over

## 🔬 Model Architecture

```
Input (128×128×3)
    │
MobileNetV2 (ImageNet weights, frozen in phase 1)
    │
GlobalAveragePooling2D
    │
Dense(256, ReLU) → BatchNorm → Dropout(0.45)
    │
Dense(128, ReLU) → Dropout(0.30)
    │
Dense(5, Softmax)   ← 5 disease classes
```

**Training Strategy:**
- Phase 1: Train head only, LR = 1e-3
- Phase 2: Fine-tune layers 100+, LR = 1e-5
- Data augmentation: rotations, flips, zoom, brightness shifts
- Callbacks: EarlyStopping + ReduceLROnPlateau + ModelCheckpoint

For production-level accuracy, use the **PlantVillage dataset**:

```bash

# https://www.kaggle.com/datasets/emmarex/plantdisease

# Option 2: Official TF Datasets
pip install tensorflow-datasets
```

Then replace the `dataset/` folder with real images organised as:
```
dataset/
  train/
    Tomato_Early_blight/  ← use folder name as class label
    Tomato_Late_blight/
    …
  test/
    …
```

## 🔧 Troubleshooting

| Problem | Solution |
|---|---|
| `ModuleNotFoundError: tensorflow` | `pip install tensorflow` |
| `Model not found` error in browser | Run `python train.py` first |
| App says "Model Offline" | Train the model, then restart `python app.py` |
| Slow training on CPU | Normal. Reduce `EPOCHS` in `train.py` to 10 |
| PIL / Pillow errors | `pip install --upgrade Pillow` |
| Port 5000 already in use | Change port in `app.py`: `app.run(port=5001)` |
